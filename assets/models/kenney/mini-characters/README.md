# Đặt model Kenney tại đây

Ưu tiên thư mục glTF/GLB trong gói tải về. Copy cả thư mục chứa model,
giữ nguyên tên và đường dẫn texture, file .bin đi kèm.
Không chỉ copy riêng .gltf nếu nó tham chiếu file bên ngoài.

Không cần đổi tên model. Xem README.md ở gốc project để gắn model vào Player.
Giữ kèm license gốc của bộ asset. Project chưa kèm asset Kenney.
